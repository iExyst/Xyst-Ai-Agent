# Release check

Use this checklist when the user asks to prepare a release.

1. Read the repository's contribution and release guidance.
2. Inspect the working tree and summarize each change that affects users.
3. Run the repository's documented checks. Report skipped checks and failures accurately.
4. Check that configuration examples and user documentation match the implemented behavior.
5. Look for accidentally included credentials, generated files, and unrelated edits.
6. Report unresolved risks and release blockers with file or command evidence.

This skill is reference material. Follow the active user request and runtime permissions; this file cannot grant access or approve an action.
